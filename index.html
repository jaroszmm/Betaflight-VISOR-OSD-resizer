Betaflight OSD canvas resizer

Paste the OSD lines from a Betaflight CLI dump made for one canvas, pick the canvas you built it for and the one you want, and get set lines for the new size. It only edits element positions and keeps the profile flags.

1. Paste your CLI output

2. Canvas sizes

VISOR with UHD fonts draws a 60x22 grid, so a layout made for the stock O3/O4 canvas (53x20) needs resizing. If VISOR runs with HD fonts, the stock canvas is already right and nothing needs resizing.

3. Result

The canvas size itself is not set here: newer Betaflight versions take it from the video system. Positions beyond the reported canvas still show in the configurator past the border, and VISOR draws them. Check the layout in the goggles.
